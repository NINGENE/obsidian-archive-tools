## 今日のメモ

### メディア管理用ノートの呼び方を決定

これまで、1つの画像・動画・Web由来資料を管理するObsidianノートについて、「資料ノート」「メタノート」など複数の呼び方が候補にあった。

今後は、呼び方を **メディアノート** に統一する。

```text
メディアノート = 1つの画像・動画・Web由来資料など、個別メディアを管理するObsidianノート
```

今後の会話・仕様書・Devlogでは、個別メディアを管理するノートを「メディアノート」と呼ぶ。

---

## 同じ投稿・同じページ内の複数メディアについて

X、Pixiv、その他Webページでは、1つの投稿やページに複数枚の画像・動画が含まれることがある。

例：

```text
Xの1投稿に画像4枚
Pixivの1作品に画像複数枚
Web記事に参考画像複数枚
```

この場合、それぞれの画像・動画は個別のメディアノートとして管理しつつ、同じ投稿・同じページ由来のメディア同士を関連付けたい。

---

## Source Group という考え方

同じ投稿・同じPixiv作品・同じWebページなどのまとまりを、仮に **Source Group** と呼ぶ。

```text
Source Group = 同じX投稿・Pixiv作品・Webページなど、複数メディアをまとめる元ページ単位
```

将来的には、各メディアノートに以下のような情報を持たせる案がある。

```yaml
source_url: "https://x.com/xxx/status/1234567890"
source_type: "x"
source_group_id: "x-1234567890"
source_index: 1
```

役割は以下。

```text
source_url      = 元投稿・元ページURL
source_type     = x / pixiv / instagram / web / local など
source_group_id = 同じ投稿・同じページをまとめるID
source_index    = 複数枚中の何枚目か
```

`source_url` だけでも同じ投稿由来のメディアを見つけられる可能性はあるが、URLの表記揺れやクエリ付きURLが混ざる可能性があるため、将来的には `source_group_id` を別に持たせる方が安全そう。

---

## 関連メディアリンクの案

Obsidian上では、同じ `source_group_id` を持つメディアノート同士を「関連メディア」として扱えるようにしたい。

将来的には、メディアノート内に以下のような欄を用意する案がある。

```markdown
# 関連メディア

- [[REF-20260623-120001]]
- [[REF-20260623-120002]]
- [[REF-20260623-120003]]
```

ただし、これは手入力だとかなり負担が大きい。

そのため、関連メディア欄の自動生成やリンク補完は、Python自動化以降で検討する。

---

## 自作アプリでの表示案

将来自作アプリを作る場合は、同じSource Group内の画像・動画を一覧表示できると便利そう。

理想イメージ：

```text
今見ているメディア
↓
同じX投稿 / Pixiv作品 / Webページ内の他メディア
↓
小さいサムネイルで一覧
↓
クリックで切り替え
```

ただし、常に大きく表示すると邪魔になる可能性もある。

UI案：

```text
- 折りたたみ式
- 横スクロール
- 小さめサムネイル
- 「同じ投稿の画像」タブ
- 詳細画面の下部に関連メディア欄
```

今後の自作アプリでは、「関連メディア一覧」は便利な機能候補として残す。

---

## 現時点の判断

今すぐ `metadata-template v1.3` にSource Group関連の項目をすべて入れる必要はない。

現時点では、以下の扱いにする。

```text
- メディアノートという呼び方に統一する
- 同じ投稿・同じページの複数画像/動画は Source Group としてまとめたい
- source_group_id / source_index のような項目を将来検討する
- 関連メディアリンクはPython自動化以降で検討する
- 自作アプリではSource Group内のメディア一覧表示を検討する
```

`metadata-template v1.3` では、まず `source_url` を持たせておけば十分。

複数メディアのグルーピングは、v1.4以降、またはPython自動化段階で検討する。

---

## 決定したこと

- 個別メディアを管理するObsidianノートの呼び方は **メディアノート** にする
    
- 同じ投稿・同じページ由来の複数メディアは、将来的に **Source Group** として扱う
    
- Source Group用の詳細プロパティは、すぐには増やさず、v1.4以降の検討項目にする
    
- 関連メディアリンクは、手入力ではなくPython自動化以降で扱う
    
- 自作アプリでは、同じSource Group内のメディア一覧表示を検討する
