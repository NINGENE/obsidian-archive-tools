
## Obsidianの一覧表示から得たアプリUI要件メモ

ObsidianでBasesとNotes Explorerを使っていて、将来自作アプリに入れたい表示切り替え機能が見えてきた。

### Notes Explorer と Bases の違い

Notes Explorerは、ノートそのものをサムネイル・プレビューのように表示できる。  
そのため、メディアノート本文の雰囲気や内容を含めて見返しやすい。

一方で、Basesは `thumbnail` プロパティに指定した画像をサムネイルとして表示できる。  
タグやプロパティなどの情報も表示できるが、ノート本文そのものをカード上で読む用途には向いていない。

整理すると以下。

```text
Notes Explorer:
  ノートそのものをプレビューする表示に近い

Bases:
  thumbnail プロパティに指定した画像を表示する
  タグやプロパティを一緒に表示できる
  ノート本文そのものは見えない
````

### 自作アプリで欲しい表示モード

将来自作アプリでは、以下のような表示モードを切り替えられるようにしたい。

```
1. メディアサムネイル表示
   - 画像・動画サムネイルを大きく見る
   - Basesの画像サムネイル表示に近い

2. ノートプレビュー表示
   - メディアノートそのものをカード化して見る
   - Notes Explorerに近い

3. メタデータ付きカード表示
   - サムネイル + タグ + 作者 + 作品名 + キャラクター名などを表示
   - 整理・確認向き

4. 詳細リスト表示
   - サムネイルは小さめ
   - プロパティを多めに表示
   - 管理・修正向き
```

見るための表示、整理するための表示、確認するための表示を切り替えられると便利そう。

### 自作アプリ要件候補

- 表示モードを切り替えられる
- サムネイルのみのギャラリー表示
- メディアノート本文を含むプレビュー表示
- サムネイル + 任意プロパティのカード表示
- 詳細リスト表示
- 表示するプロパティをユーザーが選べる
- ギャラリーのカードサイズを変更できる
