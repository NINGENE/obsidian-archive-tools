### 1. `load_config()` — config.yaml を読み込む

```
import yamlfrom pathlib import Path
def load_config(config_path: str) -> dict:    with open(config_path, encoding="utf-8") as file:        return yaml.safe_load(file)
```

**ポイント：**

- `PyYAML`（外部ライブラリ）を使う → `pip install pyyaml` が必要
- `yaml.safe_load()` がYAMLをPythonのdictに変換してくれる
- `with open()` はファイルを自動でclose()してくれる安全な書き方

---

### 2. `build_paths()` — フルパスを組み立てる

```
def build_paths(config):    vault = Path(config['vault_dir'])    inbox = vault / config['inbox_dir']    processed = vault / config['processed_dir']    failed = vault / config['failed_dir']    originals = vault / config['originals_dir']    thumbnails = vault / config['thumbnails_dir']    notes = vault / config['notes_dir']    logs = vault / config['logs_dir']
    return {        "inbox": inbox,        "processed": processed,        "failed": failed,        "originals": originals,        "thumbnails": thumbnails,        "notes": notes,        "logs": logs,    }
```

**ポイント：**

- `pathlib`（標準ライブラリ）を使う → インストール不要
- `Path(文字列)` でPathオブジェクトになる
- `vault / "フォルダ名"` でパスをつなげられる
- 複数の値を返すときはdictにまとめると管理しやすい

- 標準ライブラリと外部ライブラリの違い
