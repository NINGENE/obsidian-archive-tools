# Roadmap

Obsidian自動化・資料管理ツール制作の大きな進行計画。

## Milestone 1：手動運用を固める

### 目的

Python自動化前に、Obsidian上の保存形式を固める。

### 完了条件

- [ ] メタデータテンプレート v1.1 がある
- [ ] tags と virtual_folder の使い分けが決まっている
- [ ] 画像1枚を手動で登録できる
- [ ] Obsidianから実データへリンクできる
- [ ] GitHubで管理するもの・しないものの線引きが決まっている

---

## Milestone 2：Python最小自動化

### 目的

画像1枚から必要ファイルを自動生成する。

### 完了条件

- [ ] IDを自動生成できる
- [ ] originals にコピーできる
- [ ] thumbnails を生成できる
- [ ] Markdownノートを生成できる
- [ ] Obsidian上で生成結果を確認できる

---

## Milestone 3：複数ファイル対応

### 目的

複数画像をまとめて登録できるようにする。

### 完了条件

- [ ] 複数画像を処理できる
- [ ] 重複IDが発生しない
- [ ] エラー時にログが出る
- [ ] 途中で失敗しても再実行できる

---

## Milestone 4：入力補助

### 目的

URL、作者名、タグ、仮想フォルダーを楽に入力できるようにする。

### 完了条件

- [ ] CLIまたは簡易フォームで情報を入力できる
- [ ] 入力内容がMarkdownに反映される
- [ ] 未入力項目をあとから編集できる
- [ ] 入力ミスを修正しやすい形式になっている

---

## Milestone 5：GUI / アプリ化検討

### 目的

将来の独立アプリ化に向けたUIを考える。

### 完了条件

- [ ] Qt/Pythonで簡単なモックを作る
- [ ] 一覧表示ができる
- [ ] サムネイル表示ができる
- [ ] タグ検索ができる
- [ ] 仮想フォルダー表示ができる

---
